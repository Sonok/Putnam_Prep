# Small cases and patterns

**What it is.** Work the problem for n = 1, 2, 3, 4 by hand, guess the pattern, then prove the guess.

**Reach for it when.** The problem has a parameter n, or asks "find all" or "determine", and you do not know the answer yet. This is the first move on almost every A1 and B1.
